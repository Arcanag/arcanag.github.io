01 / The situation

PM overhead scales with team size.

Parsing requirements, assigning work and writing status reports is mechanical. I built the tool I kept wishing existed — a personal project, not a work deployment.

3
intake channels: email, Slack, meetings
6
mechanical jobs, one agent each
5
packages in one monorepo

Automate the mechanical. Preserve the judgment.

Every agent boundary sits where human product thinking begins.

02 / The system

Specialists, not a generalist.

Each agent has one job, a clear input/output contract, and can be tested on its own. Deciding where those boundaries sit was a product decision, not an architecture one.

03 / Forecasting

Dates are distributions.

The Timeline agent runs a Monte Carlo simulation across the dependency graph and returns three dates, not one: aggressive, realistic and conservative.
