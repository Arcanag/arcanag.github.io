01 / The token bleed

Too much text. Every request.

Concatenate a resume and a job description, ask the model to “make this match” — and you’ve spent 2,000+ input tokens before it writes a word. Multiply by thousands of users and the API bill becomes your biggest cost.

800–1200
words in a typical resume
500–1000
words in a job description
2000+
input tokens, sent naively

When I built a resume-tailoring tool, I treated token cost as a first-class constraint. The model receives only the structured gap between resume and job description — never the raw documents.

Input tokens per request · ~85% fewer, and better output because the problem arrives pre-digested.

Every token you send to an LLM should be one that only an LLM can process.

If Python can do it — keyword matching, readability scoring, entity extraction — Python should do it.

03 / Zero-token scoring

$0 scoring. Under 100ms.

The ATS compatibility score uses no LLM at all. Users get an instant score while the tailoring runs in the background — and the fast part is free.

Parsability

Can an ATS read it?

Section extraction, standard headers.

Keywords

Does it match?

TF-IDF cosine similarity, weighted by section.

Formatting

Will it survive?

Layout detection, font inference, no graphics.

Structure

Is it complete?

Required sections, chronology, date formats.

04 / SQLite vs Postgres

Two products. Two databases.

I built two products on the same day and chose different databases for each. Concurrency and query complexity decided it — not habit.

05 / BYOK as cost architecture

Their key. Their bill.

Bring-your-own-key isn’t only a pricing decision. It decouples scaling from LLM spend.

Cost

No token margin to manage

No throttling heavy users, no surprise bills.

Trust

Users control their data flow

Directly to the LLM provider.

Pricing

$9/month, transparent

Platform fee and LLM cost stay separate.

Scale

Costs track compute

Cheap compute, not expensive tokens.

User enters key→ Browser sends to server→ Server · encrypted storage, rate limits→ Claude API

The key never leaves the server · rate limits stop UI bugs burning tokens.

The trade-off is onboarding friction. For technical professionals changing roles, getting an API key is a 2-minute task.

06 / Putting it together

~$5 a month. Full stack.

Lean isn’t cheap for its own sake. Every dollar goes where it improves the user’s outcome.

ComputeSingle container — no database server, Redis or queue · ~$5/mo
DatabaseSQLite file + uploaded PDFs · $0
LLMBYOK — the user pays · $0
PreprocessingPython libraries · $0
Total~$5/month
The naive stackManaged Postgres ($20–50/mo), Redis ($15/mo), LLM costs absorbed by the platform — plus the overhead of running it all.

The same principle runs through Agentic PM: the decomposition agent parses structure, finds dependencies and estimates complexity heuristically, and sends only the ambiguous parts to the model.

Token consciousness isn’t premature optimisation. It’s product architecture.
