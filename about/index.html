02 / What I believe

Four principles. Learned shipping AI.

  1. 01

    The customer’s ROI metric is the roadmap’s anchor.

    The metric that defines value for the customer is the same metric that should order the backlog.

  2. 02

    Outcome → opportunity → solution.

    Product building starts with the outcome for the business, then the opportunity or problem that unlocks it — not the other way around.

  3. 03

    Influence comes from insight, not authority.

    The best product decisions start with aggregate data that makes the problem undeniable.

  4. 04

    Complexity is a symptom, not a strategy.

    Enterprise AI products rarely fail because the model is wrong. They fail because no one owned the seams between systems.
